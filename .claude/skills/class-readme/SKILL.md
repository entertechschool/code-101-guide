# Generador de README de Clase

Este skill genera READMEs de clase siguiendo el estándar del curso (leer nombre de README.md raíz). El documento es leído por el **estudiante antes de llegar a clase**.

## Principios Fundamentales

| Principio | Descripción |
|-----------|-------------|
| **Audiencia** | Estudiante que lee ANTES de llegar a clase |
| **Tono** | Segunda persona: "descubrirás", "aprenderás", "crearás" |
| **Propósito** | Motivar, preparar, dar contexto |
| **Evitar** | Jerga pedagógica: "Warm-up", "Momento WOW", "Validación", tiempos exactos |

## Ejemplos de Secciones Bien Escritas

### Resumen

> En esta clase, descubrirás cómo funciona la web moderna—desde que escribes una URL hasta que ves una página en tu navegador. Es un viaje fascinante que involucra clientes, servidores, protocolos y código.
>
> Configurarás tu entorno de desarrollo profesional con Visual Studio Code, el editor que usan millones de desarrolladores en el mundo.
>
> Al final de la clase, tendrás tu primera página web funcionando con tu nombre, foto y hobbies.

### ¿Por qué te sirve?

> - **HTML tiene más de 30 años y sigue siendo la base de toda la web.** Frameworks van y vienen, pero HTML permanece. Lo que aprendas hoy te servirá toda tu carrera.
>
> - **El modelo cliente-servidor no solo aplica a páginas web.** Es el mismo que usa Netflix, Spotify, o cualquier app que se conecte a internet.
>
> - **Configurar bien tu entorno desde el inicio te ahorra horas después.** Los profesionales invierten tiempo en sus herramientas porque multiplica su productividad.

### 🎯 ¿Qué haremos en clase?

> 1. **Exploraremos cómo funciona la web** - Descubrirás qué pasa "detrás de escenas" cuando visitas un sitio.
> 2. **Configurarás VS Code** - Instalarás las extensiones que usan los desarrolladores profesionales.
> 3. **Crearás tu primera página** - Escribirás HTML real y verás los cambios en tiempo real.
> 4. **Mostrarás tu trabajo** - Presentarás tu página al grupo.

## Lo que NO va en este README

Esto pertenece a `facilitator/README.md`:

- Tiempos exactos por fase (10 min, 50 min)
- Nombres de fases pedagógicas (Warm-up, Momento WOW, Validación)
- Estrategias de enseñanza
- Cómo manejar errores comunes de estudiantes
- Señales de comprensión vs confusión
- Tips para diferenciación
- Gestión del tiempo

## Checklist de Verificación

Antes de finalizar, verificar:

- [ ] ¿Está en segunda persona? ("descubrirás", no "los estudiantes descubrirán")
- [ ] ¿Tiene la sección "¿Por qué te sirve?"?
- [ ] ¿La sección "¿Qué haremos?" NO tiene tiempos ni jerga pedagógica?
- [ ] ¿Los objetivos usan verbos de acción medibles?
- [ ] ¿La preparación es práctica y accionable?
- [ ] ¿No hay información que pertenezca al facilitator?

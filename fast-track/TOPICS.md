## Resumen del curso
- **Qué construye el estudiante:** Un único proyecto integrador, "Mi Portfolio Dev": sitio web personal de una página con 6 secciones (Hero, About, Skills, Projects, Contact, Footer), HTML semántico, CSS con variables y Flexbox, diseño responsive, validación de formulario y menú móvil en JavaScript, publicado en GitHub Pages.
- **Formato según README:** Programa intensivo de 4 días para completar Code 101 de forma acelerada; 4 sesiones de 120 min + 1 día de entrega asíncrona (Día 5); modalidad workshop práctico (code-along). Sin slides ni tests diagnósticos; Git desde el día 1.
- **Perfil de entrada según README:** "estudiantes que necesitan completar Code 101 de forma acelerada". Requisitos: VS Code instalado, cuenta de GitHub activa, Git instalado, internet estable, navegador Chrome o Firefox.
- **Herramientas y tecnologías:** HTML, CSS, CSS Variables (`:root`), Flexbox, media queries, JavaScript, DOM, eventos, Visual Studio Code (VS Code), Live Server, terminal, Git, GitHub, GitHub Pages, Chrome DevTools, Google Fonts, Canvas (entrega final), navegador Chrome o Firefox.
- **Proyectos:** Día 1–4: Mi Portfolio Dev (un solo proyecto integrador que evoluciona cada día)

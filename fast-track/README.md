# Fast-Track: Mi Portfolio Dev

> **Programa intensivo de 4 días** para estudiantes que necesitan completar Code 101 de forma acelerada.

---

## Formato del Programa

| Aspecto | Detalle |
|---------|---------|
| **Duración** | 4 sesiones + 1 día de entrega async |
| **Horario** | Lunes a Jueves, 8:00 - 10:00 PM |
| **Duración por sesión** | 120 min |
| **Modalidad** | Workshop práctico (code-along) |
| **Entrega final** | Día 5 (viernes) vía Canvas |

---

## Proyecto: Mi Portfolio Dev

Un sitio web personal de una página que demuestra competencias en HTML, CSS y JavaScript básico.

### Secciones del Portfolio

| Sección | Contenido |
|---------|-----------|
| **Hero** | Nombre, título profesional, foto placeholder |
| **About** | Breve biografía, objetivos e intereses |
| **Skills** | Cards con tecnologías/habilidades |
| **Projects** | Cards con proyectos y enlaces |
| **Contact** | Formulario de contacto funcional (frontend) |
| **Footer** | Enlaces sociales y copyright |

### Tecnologías

| Día | Tecnologías |
|-----|-------------|
| 1 | HTML semántico, CSS básico, Git |
| 2 | CSS Variables, Flexbox, responsive |
| 3 | JavaScript: DOM, eventos, validación |
| 4 | GitHub Pages, pulido, deploy |

---

## Cronograma

### Día 1: HTML + CSS Base + Git Setup

| Min | Actividad |
|-----|-----------|
| 0-5 | Micro-lecture: "Cómo funciona una página web" |
| 5-15 | Setup: VS Code, Live Server, crear repo en GitHub, clonar |
| 15-35 | HTML: nav, hero, about (con lista intereses) |
| 35-55 | HTML: skills, projects (cards), contact (form), footer |
| 55-60 | Break |
| 60-105 | CSS: reset básico, Google Fonts, estilos directos (nav, hero, botón, secciones, cards, form, footer base) |
| 105-115 | Buffer: personalización (textos, colores, contenido propio) |
| 115-120 | `git add . && git commit && git push` |

**Resultado:** Página completa con HTML semántico (6 secciones) y CSS base con estilos directos.

### Día 2: CSS Variables + Flexbox + Responsive

| Min | Actividad |
|-----|-----------|
| 0-5 | Micro-lecture: "Flexbox y Responsive" |
| 5-30 | CSS Variables (parcial) + sticky nav + btn hover |
| 30-55 | Flexbox: nav responsive + hamburger |
| 55-60 | Break |
| 60-95 | Flexbox: cards + footer expandido + hero desktop |
| 95-110 | Media query responsive + verificar con DevTools |
| 110-115 | Buffer / troubleshooting |
| 115-120 | Commit + push |

**Resultado:** Layout profesional con Flexbox y responsive. Tarea: completar refactoring de variables.

### Día 3: JavaScript

| Min | Actividad |
|-----|-----------|
| 0-5 | Micro-lecture: "JS: lo mínimo necesario" |
| 5-15 | Conectar script.js, console.log test |
| 15-60 | Validación de formulario completa |
| 60-65 | Break |
| 65-100 | Menú móvil toggle |
| 100-115 | Buffer / testing / debugging |
| 115-120 | Commit + push |

**Resultado:** Portfolio interactivo con validación y menú móvil. Tarea: 1-2 logros adicionales.

### Día 4: Deploy + Pulido

| Min | Actividad |
|-----|-----------|
| 0-5 | Micro-lecture: "Git y GitHub Pages en 5 min" |
| 5-25 | Activar GitHub Pages, verificar deploy, probar URL |
| 25-30 | Break |
| 30-80 | Pulido: arreglar issues visuales, mejorar responsive, ajustar colores |
| 80-100 | Auto-revisión con rúbrica (checklist criterio por criterio) |
| 100-115 | Commit final + push + verificar deploy actualizado |
| 115-120 | Instrucciones de entrega Canvas (Día 5) + cierre del programa |

**Resultado:** Portfolio publicado en GitHub Pages, revisado con rúbrica.

### Día 5: Completar + Entregar (async)

Sin clase presencial. El estudiante trabaja de forma independiente:

1. **Completar tareas pendientes** de Days 2-4:
   - Day 2: Refactoring de variables CSS (5 secciones)
   - Day 3: Logros adicionales opcionales
   - Day 4: Personalizar contenido + auto-revisión con rúbrica
2. **Push final** + verificar deploy en GitHub Pages
3. **Enviar por Canvas** antes del deadline (viernes 11:59 PM):
   - URL de GitHub Pages: `https://[usuario].github.io/mi-portfolio-dev/`
   - URL del repositorio: `https://github.com/[usuario]/mi-portfolio-dev`

## Sistema de Evaluación

### Rúbrica (4 criterios × 25 pts = 100)

| Criterio | Evalúa |
|----------|--------|
| 1. Estructura y Git | HTML semántico + historial de commits |
| 2. Diseño Responsive | CSS + Flexbox + media queries |
| 3. Interactividad | JavaScript: validación + menú |
| 4. Publicación | GitHub Pages funcional + contenido personalizado |

Ver rúbrica completa en [rubric.md](rubric.md).

### Escala de Calificación

| Rango | Nota | Descripción |
|-------|------|-------------|
| 90-100 | A | Excelente - Dominio completo |
| 80-89 | B | Bueno - Comprensión sólida |
| 70-79 | C | Satisfactorio - Cumple requisitos |
| < 70 | F | Necesita mejora |

## Diferencias con Code 101 Regular

| Aspecto | Code 101 Regular | Fast-Track |
|---------|-----------------|------------|
| Duración | 12 clases × 3h | 4 sesiones × 2h |
| Formato | Blend (teoría + práctica) | Workshop (code-along) |
| Proyecto | 3 proyectos separados | 1 proyecto integrador |
| Slides | Sí (reveal.js) | No (demo en vivo) |
| Tests diagnósticos | Sí (por módulo) | No (rúbrica es la evaluación) |
| Git | Desde clase 5 | Desde día 1 |

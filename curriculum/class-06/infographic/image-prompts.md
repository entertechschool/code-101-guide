# Image Prompts — Clase 06: Diseño Web Responsive + DevTools

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

---

**Sin imágenes requeridas.**

Toda la infografía se representa con HTML y CSS puros: los dispositivos (móvil, tablet, desktop) están hechos con `<div>` estilizados, las unidades relativas con tablas, los breakpoints con cards y los bloques de código con `<pre>` resaltado inline. No hay tags `<img>` en `index.html`.

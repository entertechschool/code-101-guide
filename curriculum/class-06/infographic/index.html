Unidades Relativas

Reemplaza valores fijos en px por unidades que escalan con la pantalla y la accesibilidad del usuario.

px Fijo. No se adapta a nada. bordes, sombras
rem Relativo a la fuente raíz (16px). texto, padding
% Relativo al elemento padre. anchos
vh / vw % de la altura/ancho del viewport. secciones full-screen 
.container {
    width: 90%;              /* Flexible */
    max-width: 600px;        /* Pero con tope */
    font-size: 1rem;         /* = 16px escalable */
    padding: 2rem;           /* = 32px escalable */
}

Media Queries

Reglas CSS condicionales: aplican estilos solo cuando se cumple una condición de pantalla. Tu CSS se vuelve sensible al contexto.

/* Estilos base: móvil */
h1 {
    font-size: 1.5rem;
}

/* Solo si la pantalla es 768px o más */
@media (min-width: 768px) {
    h1 {
        font-size: 2.5rem;
    }
}

Mobile-First

Estrategia moderna: empieza por la versión móvil y agrega complejidad para pantallas más grandes con min-width. Es más fácil sumar que quitar.

/* ❌ Desktop-First (antiguo) */
h1 { font-size: 3rem; }
@media (max-width: 768px) { /* quitar cosas */ }

/* ✅ Mobile-First (moderno) */
h1 { font-size: 1.5rem; }
@media (min-width: 768px) { /* agregar cosas */ }
Viewport Área visible de la página en el navegador
Breakpoint Ancho donde el diseño cambia (ej: 768px)
rem 1rem = tamaño de fuente raíz (16px)
vh / vw 1% del alto/ancho del viewport

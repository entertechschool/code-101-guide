Unidades relativas, Media Queries y Chrome DevTools

Más del 60% del tráfico web viene de celulares. Un sitio que solo se ve bien en laptop pierde a la mayoría de visitantes — y Google penaliza en su ranking a los que no son mobile-friendly.

2. Chrome DevTools — Rayos X para tu sitio

Las herramientas de desarrollo del navegador te dejan inspeccionar HTML/CSS, modificarlo en vivo y simular cualquier dispositivo sin tener uno físico. Es la herramienta #1 para resolver problemas de diseño.

// Atajos esenciales

Ctrl + Shift + M   // Activar modo dispositivo (responsive)
Ctrl + Shift + C   // Inspeccionar un elemento con el mouse

3. Unidades relativas: deja los píxeles fijos

Los valores en px son rígidos. Las unidades relativas escalan con el contexto — el tamaño de fuente raíz, el padre, o el viewport. Más flexibles, más fáciles de mantener.

rem Relativo al tamaño de fuente raíz (`html`). Si raíz = 16px, `1rem` = 16px.
% Porcentaje del elemento padre. Ideal para anchos fluidos.
vh / vw Porcentaje de la altura/ancho del viewport. `100vh` = pantalla completa.
em Relativo al tamaño de fuente del padre. Útil para escalar componentes.

4. Media Queries: reglas que se activan por tamaño

Una @media query es una regla CSS que solo aplica cuando se cumple una condición de pantalla. Es lo que hace que tu sitio se reacomode al cambiar de dispositivo.

/* Estilos base: aplican a TODO (mobile-first) */
.card { padding: 1rem; }

/* Cuando la pantalla mide 768px o más (tablet/desktop) */
@media (min-width: 768px) {
  .card { padding: 2rem; }
}

/* Breakpoints comunes: 480px · 768px · 1024px · 1440px */
Viewport El área visible de la página en el navegador. Cambia según el dispositivo y la orientación.
Breakpoint Punto donde el diseño cambia (ej: 768px). Decides los breakpoints según tu contenido, no los dispositivos.
Mobile-First Diseñar primero para móvil y escalar hacia pantallas grandes con min-width. Filosofía profesional estándar.

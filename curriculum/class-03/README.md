# Estilos con CSS

## Resumen

En esta clase, transformarás tu perfil de una página estructurada pero visualmente plana a un diseño con identidad propia. Descubrirás CSS—el lenguaje que da vida visual a las páginas web—y lo usarás para aplicar colores, tipografías y espaciado.

Elegirás una paleta de colores que te represente, seleccionarás tipografías de Google Fonts, y aprenderás el Box Model: el concepto fundamental que controla cómo se distribuye el espacio en una página web.

Al final de la clase, tu perfil tendrá una identidad visual coherente: colores que combinan, tipografía elegante, y espaciado profesional. La transformación será dramática—y la harás tú.

---

## ¿Por qué te sirve?

- **CSS es el lenguaje universal del diseño web.** Toda página que hayas visto—desde Google hasta Netflix—usa CSS para su apariencia. Aprenderlo te da control total sobre cómo se ve tu contenido.

- **El Box Model es la base de todo layout.** Una vez que entiendas cómo funciona el espacio en CSS (content, padding, border, margin), podrás construir cualquier diseño que imagines.

- **Las decisiones de diseño comunican.** Los colores y tipografías que elijas dicen algo sobre ti. Tu perfil no solo mostrará información—transmitirá tu personalidad.

---

## ¿Qué haremos en clase?

1. **Veremos la magia de CSS en acción** - Descubrirás cómo un solo archivo puede transformar completamente una página HTML.

2. **Elegirás tu paleta de colores** - Usarás herramientas profesionales para crear una combinación de colores coherente y atractiva.

3. **Configurarás tipografía con Google Fonts** - Seleccionarás fuentes que complementen tu diseño y aprenderás a implementarlas.

4. **Dominarás el Box Model** - Entenderás cómo controlar el espacio con padding, margin y border para crear layouts profesionales.

---

## Objetivos de Aprendizaje

Al finalizar esta clase, podrás:

1. **Vincular** un archivo CSS externo a un documento HTML
2. **Aplicar** selectores de elemento, clase e id para estilizar
3. **Explicar** el Box Model (content, padding, border, margin)
4. **Configurar** tipografía usando Google Fonts
5. **Crear** una paleta de colores coherente para tu proyecto

## Glosario

| Término | Definición |
|---------|------------|
| **CSS** | Cascading Style Sheets - Lenguaje para estilizar HTML |
| **Selector** | Indica QUÉ elementos estilizar (`h1`, `.clase`, `#id`) |
| **Propiedad** | QUÉ aspecto cambiar (`color`, `font-size`, `margin`) |
| **Valor** | CÓMO cambiarlo (`red`, `16px`, `20px`) |
| **Box Model** | Modelo de caja: content + padding + border + margin |
| **Padding** | Espacio interno (entre contenido y borde) |
| **Margin** | Espacio externo (entre el elemento y otros) |
| **Google Fonts** | Servicio gratuito de tipografías web |

Concepto clave

El Box Model

Todo elemento HTML es una caja con 4 capas. Entender esto es la base de todo layout en CSS.

  • content — El contenido real (texto, imagen)
  • padding — Espacio interno entre contenido y borde
  • border — El borde visible del elemento
  • margin — Espacio externo entre elementos

Estilos y Box Model

La Matrix del Diseño: Cascada, Selectores y el control del espacio

1. Anatomía de una Regla CSS

HTML es el esqueleto; CSS es la ropa. Toda regla necesita un selector (a quién), una propiedad (qué) y un valor (cómo).

/* Conectar en el HTML con: <link rel="stylesheet" href="styles.css"> */

h1 {
    color: #38bdf8;
    background-color: #0f172a;
}

2. La Matrix (Cascada y Herencia)

Dos principios fundamentales de cómo el navegador lee y aplica los estilos.

⬇️ Cascada

CSS se lee de arriba hacia abajo. Si dos reglas se contradicen para el mismo elemento, la última línea escrita gana.

🧬 Herencia

Las propiedades de texto (como font-family y color) aplicadas a un contenedor padre, pasan a sus hijos solos (como del body a los `p`).

3. Los 3 Selectores Clave

A quién le disparo el dardo. El nivel de exclusividad que le das a una regla de diseño CSS.

Etiqueta

h1 { }

Muy global. Afecta a todos los <h1> de la página por igual.

ID

#experiencia { }

Exclusivo. Afecta a un solo elemento de la página. Como un DNI.

Clase

.btn-rojo { }

Reusable. Afecta a un grupo de elementos que comparten `class="btn-rojo"`.

4. El Modelo de Caja (Box Model)

Todo en la web es un rectángulo. El Box Model dicta cómo se distribuyen sus capas de adentro hacia afuera: el relleno da aire, el borde encierra, el margen empuja.

Margin (Afuera)
Border (El Límite)
Padding (Adentro)
CONTENT (Texto/Imagen) 
section {
    padding: 20px;  /* Aire dentro de la sección */
    margin: 40px;   /* Empuja a las secciones vecinas */
    border: 2px solid black;
}
Normalización (`*`) Regla CSS (`* { margin:0; padding:0; }`) usada al inicio para borrar los estilos por defecto que pone Chrome. Arrancamos con un lienzo limpio.
Padding Espacio interno. Empuja el contenido hacia el centro para que no golpee los bordes.
Margin Espacio externo. La "burbuja de espacio personal" que separa tu caja del resto.

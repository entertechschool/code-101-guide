# Image Prompts — Clase 03: Estilos con CSS

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

---

> **Nota:** Esta infografía no requiere imágenes externas generadas por IA. Todos los conceptos (Reglas CSS, Cascada, Selectores Clave, Box Model completo) se diseñaron directamente con elementos visuales de CSS, layouts HTML y bloques de código con resaltado sintáctico, manteniendo el diseño fluido y la exportación de alta calidad nativa en el navegador.

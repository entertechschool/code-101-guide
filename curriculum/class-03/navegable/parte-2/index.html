Cascada

Concepto

¿Qué es la cascada? La manera en que el navegador decide qué regla gana cuando dos chocan.

La C de CSS viene del inglés cascading, "en cascada": las reglas caen una tras otra sobre el mismo elemento. Si dos piden cosas distintas, como dos colores para el mismo texto, el navegador se queda con una sola.

Concepto

¿Cómo elige? Primero por la prioridad del selector y, si empatan, por el orden.

La prioridad va así: id gana a class, y class gana a etiqueta. A esa prioridad también se le llama especificidad. Si las dos reglas tienen la misma, gana la que está más abajo en tu archivo.

Figura

Ejemplo

/* Para <p class="oferta">Menú del día</p> */
p {
  color: gray;
}

.oferta {
  color: green;
}

.oferta {
  color: red;
}

El texto sale rojo. .oferta le gana a p por prioridad, y entre las dos reglas .oferta, que empatan, gana la de más abajo.

Error común

Crees que siempre gana la última regla:

/* Mal: <p class="oferta"> sale verde, no azul */
.oferta {
  color: green;
}

p {
  color: blue;
}

Pasa porque p está más abajo y parece que debe ganar. El orden solo decide cuando dos reglas tienen la misma prioridad, y aquí .oferta vale más que p. Si quieres azul, cámbialo en .oferta, que es la regla que gana.

Para detectarlo, inspecciona el elemento en DevTools y mira la pestaña Styles: la declaración que perdió aparece tachada.

Herencia

Concepto

¿Qué es la herencia? Cuando un elemento recibe el estilo de su padre sin que lo escribas otra vez.

El HTML forma un árbol: cada elemento está dentro de otro, que es su padre, y los que lleva dentro son sus hijos. Si le das color al padre, sus hijos lo heredan.

Figura

Ejemplo

<div class="tarjeta">
  <h2>Menú del día</h2>
  <p>Arroz chaufa</p>
</div>
<footer>Abierto hasta las 8</footer>
.tarjeta {
  color: teal;
  text-align: center;
}

El <h2> y el <p> salen verde azulado y centrados, porque heredan de .tarjeta. El <footer> no es hijo de la tarjeta, así que queda igual.

Qué se hereda y qué no

CriterioSe heredanNo se heredan
Qué sonPropiedades del textoPropiedades de la caja
Ejemploscolor, font-family, font-size, font-weight, text-alignborder, padding, margin
Por quéUn hijo suele leerse igual que su padreCada elemento tiene su propia caja, con su borde y su espacio

border, padding y margin se explican en los pisos siguientes. Si dudas de una propiedad, inspecciona un hijo en DevTools y abre la pestaña Computed: ahí está el valor que de verdad recibió.

Error común

Le das padding al padre y esperas que cada hijo tenga su espacio:

/* Mal: esperabas 20px de espacio dentro de cada elemento */
body {
  padding: 20px;
}

Pasa porque padding, el espacio interior de una caja, parece algo que se reparte hacia los hijos. No se hereda: lo recibe solo el <body>, y sus hijos quedan con padding: 0. Para que lo tengan, escríbelo en una regla que los alcance, como p { padding: 20px; }.

Para detectarlo, inspecciona uno de los hijos en DevTools y abre la pestaña Computed: su padding aparece en 0.

Box Model

Concepto

¿Qué es el Box Model? El modelo que dice que todo elemento de una página es una caja.

El nombre significa "modelo de caja". Para el navegador, un título, un párrafo y una imagen son rectángulos, y la página entera es un conjunto de cajas dentro de otras cajas.

Figura

Concepto

¿Qué partes tiene la caja? Cuatro, de adentro hacia afuera.

Contenido
El texto o la imagen del elemento; en inglés, content.
Padding
El espacio entre el contenido y el borde.
Border
La línea que rodea al padding.
Margin
El espacio fuera del borde, que separa la caja de las demás.

Figura

Concepto

¿Para qué sirve el Box Model? Para controlar el espacio: padding da aire dentro de la caja y margin la separa de las demás.

Cada parte se puede ajustar por separado, y también lado por lado: arriba, derecha, abajo o izquierda.

Border y padding

Concepto

¿Qué es border? La propiedad que dibuja la línea alrededor de la caja.

Lleva tres valores seguidos: grosor, estilo y color. El estilo no se puede omitir: sin él, el borde no se dibuja.

Figura

Ejemplo

/* Un borde sólido de 2 píxeles alrededor de la tarjeta */
.tarjeta {
  border: 2px solid #1d3557;
}

Concepto

¿Qué es padding? El espacio entre el contenido y el borde.

Va dentro de la caja, así que el fondo de la caja también lo cubre. Para un solo lado usa padding-top, padding-right, padding-bottom o padding-left. Para varios lados a la vez, uno, dos o cuatro valores cubren casi todo lo que vas a necesitar.

Figura

Ejemplo

/* 10px arriba y abajo, 20px a los lados */
.tarjeta {
  padding: 10px 20px;
}

/* Solo espacio a la izquierda */
.cita {
  padding-left: 16px;
}

¿Cuándo usar padding?

Sí

  • Para que el texto no quede pegado al borde de una tarjeta o un botón.
  • Para que el color de fondo rodee el texto con aire.

No

  • Para separar una tarjeta de otra: eso lo hace margin.

Margin y centrar una caja

Concepto

¿Qué es margin? El espacio fuera del borde, que separa la caja de las demás.

Va fuera de la caja, así que no lleva fondo. Se escribe igual que padding: margin-top, margin-right, margin-bottom y margin-left para un lado, y uno, dos o cuatro valores para varios.

Figura

Ejemplo

/* 24px de separación en los cuatro lados */
.tarjeta {
  margin: 24px;
}

/* Solo separación abajo */
.titulo {
  margin-bottom: 12px;
}

¿Cuándo usar margin?

Sí

  • Para separar una caja de las que tiene al lado.
  • Para centrar una caja, como en los pasos de abajo.

No

  • Para dar aire entre el texto y el borde: eso lo hace padding.

Cómo centrar una caja

  1. Dale un ancho máximo con max-width: la caja no pasa de ese ancho y, en pantallas más chicas, se encoge.
  2. Agrega margin: 0 auto: 0 para arriba y abajo, y auto para los lados. 
    .tarjeta {
  max-width: 600px;
  margin: 0 auto;
}
  3. Abre la página: la caja queda centrada.

auto le pide al navegador que reparta a partes iguales el espacio que sobra a los lados. Sin un ancho, una caja de bloque ocupa todo el ancho y no sobra nada que repartir.

Error común

Usas margin cuando querías padding:

/* Mal: querías aire dentro de la tarjeta, y lo que se movió fue la tarjeta */
.tarjeta {
  margin: 20px;
}

Pasa porque los dos se escriben igual y los dos dan espacio. margin queda fuera del borde y padding queda dentro: el texto sigue pegado al borde y la tarjeta se separó de sus vecinas.

Para detectarlo, inspecciona la tarjeta en DevTools y pasa el mouse sobre ella en el panel Elements: el navegador pinta el espacio de margin y el de padding en colores distintos.

Reset

Apertura

Al principio, la web servía para compartir documentos de texto, y todavía no existía CSS. Aun así, el navegador tenía que mostrar títulos, párrafos y enlaces de forma legible, y por eso cada navegador trae sus propios estilos: el <h1> grande y en negrita, el <body> con un margen alrededor, los enlaces azules y subrayados. Se aplican aunque no escribas una sola regla, y a veces estorban. Para quitarlos existe el reset.

Concepto

¿Qué es un reset? Unas reglas al inicio de tu CSS que quitan los estilos por defecto del navegador.

Con el reset partes de una página en blanco: el espacio que veas lo pusiste tú.

Figura

Ejemplo

/* Reset básico */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

Qué hace cada parte del reset

El selector *
Alcanza a todos los elementos de la página.
margin: 0 y padding: 0
Quitan el espacio exterior e interior que pone el navegador.
box-sizing: border-box
Hace que el ancho incluya el padding y el border. Una caja de 600px con padding: 20px sigue midiendo 600px.
Bajar al piso 7

Conclusiones

Conclusión 1

Cuando varias reglas llegan al mismo elemento, el navegador decide cuál se aplica. Gana la de mayor prioridad: id, luego class, luego etiqueta. Si empatan, gana la que está más abajo. Y las propiedades del texto que nadie escribió en un elemento las hereda de su padre.

Viene de: Cascada · Herencia

Conclusión 2

Cada elemento es una caja de cuatro partes, y tú decides cuánto espacio ocupa. padding da aire por dentro, border dibuja el contorno y margin separa la caja de las demás; con max-width y margin: 0 auto queda centrada. El reset deja todo en cero para que el espacio sea el que tú escribas.

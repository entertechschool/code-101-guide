Setup y Web Moderna

Estructura web, ciclo cliente-servidor y la anatomía de HTML

1. La Trinidad de la Web

Toda página web, sin excepción, se construye con estas 3 tecnologías.

HTML

Estructura (Los Huesos)
Define qué existe en la página: títulos, párrafos, imágenes.

CSS

Apariencia (La Ropa)
Define cómo se ve: colores, tamaños, fuentes y layouts.

JavaScript

Comportamiento (El Cerebro)
Define qué hace: reacciona a clics, lógica, cambia datos.

3. Anatomía de una Etiqueta HTML

La unidad básica de instrucción para el navegador. Nombres siempre en minúsculas.

<a href="perfil.html" class="boton">Ver Perfil</a>

Nota: Algunas etiquetas como <img> son "vacías" y no tienen etiqueta de cierre ni contenido interno.

4. Tus Primeras Etiquetas

Con 5 etiquetas elementales puedes construir toda la estructura base de un sitio web.

<!-- Títulos: h1 al h6 (Solo un h1 por página) -->
<h1>Mi Título Principal</h1>

<!-- Párrafos -->
<p>Lorem ipsum dolor sit amet...</p>

<!-- Imágenes (Ruta y Accesibilidad) -->
<img src="foto.jpg" alt="Texto para lector de pantallas">

<!-- Listas Desordenadas (ul) -->
<ul>
    <li>Elemento uno</li>
    <li>Elemento dos</li>
</ul>
Etiqueta HTML La instrucción básica para el navegador. Se compone de apertura <tag>, contenido y cierre </tag>. Algunas son vacías como <img>.
Atributo alt Texto alternativo en <img>. Crucial para accesibilidad (lectores de pantalla) y si la imagen no carga.
Live Server Extensión de VS Code que convierte tu computadora en un servidor local, actualizando el navegador en tiempo real al guardar.

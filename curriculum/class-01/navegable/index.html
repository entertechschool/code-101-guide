Bajar al piso 1

Qué es una página web

Apertura

Abre cualquier página en tu navegador y mírala con atención. Hay cosas que están ahí porque alguien decidió qué va primero y qué va después. Otras están ahí para que se vea bien: colores, tamaños, espacios. Y otras pasan cuando tú haces algo, como un menú que se despliega al tocarlo.

¿Quién hace cada una de esas tres cosas? No es una sola herramienta. Son tres.

Concepto

¿Qué es una página web? Un documento que el navegador recibe por internet y dibuja en pantalla.

Toda página web se construye con exactamente tres tecnologías: HTML, CSS y JavaScript. Cada una se ocupa de una cosa distinta, y una página puede existir solo con HTML; las otras dos se suman encima.

HTML
HyperText Markup Language. El contenido y su estructura: qué textos, imágenes y listas hay, y en qué orden.
CSS
Cascading Style Sheets. La apariencia: colores, tipografías, tamaños, dónde se ubica cada cosa.
JavaScript
El comportamiento: lo que pasa cuando el usuario hace clic, escribe o se desplaza.

Bajar al piso 2

Cómo funciona la web

Concepto

¿Cómo funciona la web? Tu navegador pide una página a una computadora remota y esa computadora se la envía.

Cada vez que escribes una dirección y presionas Enter pasa lo mismo: el navegador averigua dónde está la computadora que tiene esa página, le pide el archivo, lo recibe y lo dibuja. Todo eso toma menos de un segundo, pero son varios pasos y cada uno tiene nombre.

Figura

Concepto por elemento

Cliente
El programa que pide la página. En la práctica, tu navegador (Chrome, Firefox, Safari).
Servidor
La computadora que guarda los archivos de la página y los envía a quien los pida. Está encendida todo el tiempo.
URL
Uniform Resource Locator. La dirección completa de un recurso, como https://www.google.com.pe/cursos. Dice el protocolo, el dominio y la ruta.
DNS
Domain Name System. Traduce un nombre como google.com.pe a la dirección IP del servidor. Funciona como una lista de contactos: tú recuerdas el nombre, el DNS sabe el número.
IP
El número que identifica a una computadora en la red, como 142.250.78.3.
HTTP
HyperText Transfer Protocol. Las reglas con las que el navegador y el servidor se hablan. GET es la petición de "dame este archivo". La S de HTTPS indica que la conversación va cifrada.

Ojo

El servidor no envía la página "pintada". Envía texto HTML, y es tu navegador el que lo convierte en lo que ves. Por eso dos navegadores pueden mostrar la misma página con pequeñas diferencias.

Bajar al piso 3

Sintaxis HTML: las etiquetas

Concepto

¿Qué es una etiqueta? La marca con la que HTML le dice al navegador qué es cada pedazo de contenido.

HTML es un lenguaje de marcado (Markup Language): no da órdenes, señala. Se escribe el texto normal y se rodea con etiquetas que indican "esto es un título", "esto es un párrafo". Una etiqueta de apertura y una de cierre forman, con lo que hay entre ellas, un elemento.

¿Qué es un atributo? Un dato extra que se escribe dentro de la etiqueta de apertura para configurar el elemento.

Tiene nombre y valor: nombre="valor".

Figura

Cómo se hace

  1. Escribe el nombre de la etiqueta entre < y >: <p>.
  2. Cierra con el mismo nombre y una barra: </p>.
  3. Pon los atributos solo en la apertura, separados por espacio, con el valor entre comillas: <img src="foto.jpg" alt="Mi foto">.
  4. Escribe los nombres en minúsculas: <p>, no <P>.
  5. Cierra en orden inverso al que abriste: lo último que se abre es lo primero que se cierra.

Ejemplo

<p>Bienvenido a <b>mi página</b>.</p>

<p> marca el párrafo completo. <b> marca solo las palabras en negrita y se cierra antes que </p>, porque se abrió después.

Ojo

Algunas etiquetas no tienen cierre porque no envuelven contenido: solo insertan algo. Las más usadas: <img> (imagen), <br> (salto de línea), <hr> (línea horizontal), <input> (campo de formulario).

<p>Primera línea<br>Segunda línea</p>

Error común

Cerrar las etiquetas en orden cruzado:

<p><b>mi página</p></b>

Pasa porque se cierra "la que me acuerdo" en vez de la última que se abrió. El navegador intenta arreglarlo solo y a veces lo hace, por eso el error no siempre se nota de inmediato.

Cómo detectarlo: lee las etiquetas de cierre de derecha a izquierda; deben aparecer en el orden exacto en que abriste.

Estructura de un documento HTML

Ojo: el archivo

Un documento HTML es un archivo de texto con extensión .html. El nombre va en minúsculas, sin espacios ni tildes: contacto.html, no Mi Página.html.

index.html es el nombre reservado para la página principal: cuando abres una carpeta o un dominio sin indicar archivo, el servidor busca index.html y muestra ese.

Concepto

¿Qué es la estructura de un documento HTML? El esqueleto mínimo que toda página necesita para que el navegador la interprete bien.

Ese esqueleto es siempre el mismo, línea por línea:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>

  </body>
</html>
<!DOCTYPE html>
Le dice al navegador que este archivo usa HTML moderno (HTML5). No es una etiqueta, es una declaración, y va siempre primero.
<html>
La raíz. Todo lo demás vive adentro. lang="es" indica el idioma del contenido.
<head> (cabeza)
Información sobre la página que no se ve en pantalla.
<meta charset="UTF-8">
La codificación de caracteres. Sin esto, las tildes y la ñ pueden salir como símbolos raros.
<title>
El texto que aparece en la pestaña del navegador.
<body> (cuerpo)
Todo lo que sí se ve. Aquí va el contenido de la página.

Las etiquetas que contienen a otras son su padre, y las contenidas son sus hijas: <html> es padre de <head> y <body>; <head> es padre de <meta> y <title>. La sangría (los espacios al inicio de cada línea) no cambia nada para el navegador, pero deja ver esa jerarquía de un vistazo.

Figura

Ojo: el atajo

En Visual Studio Code, en un archivo .html vacío, escribe ! y presiona Tab. El editor escribe toda la plantilla por ti. Igual tienes que saber qué hace cada línea: el atajo ahorra tipeo, no entendimiento.

Error común

Escribir contenido fuera de <body>:

  </body>
</html>
<p>Este párrafo quedó afuera</p>

Pasa al pegar o escribir al final del archivo sin mirar dónde cerró el cuerpo. El navegador suele mostrar el párrafo igual, así que el error no salta a la vista.

Cómo detectarlo: la última línea del archivo tiene que ser </html>; si hay algo después, está afuera.

Bajar al piso 5

Etiquetas de texto

Concepto: headings

¿Qué es un heading? Un título o subtítulo que organiza el contenido en niveles.

Hay seis, de <h1> a <h6> (h de heading, el número es el nivel). <h1> es el título principal de la página; <h2> divide en secciones; <h3> divide una sección; y así hasta <h6>. Por defecto el navegador los muestra en negrita y cada nivel más chico que el anterior.

<h1>Mi portafolio</h1>
<h2>Proyectos</h2>
<h3>Página de recetas</h3>

Cuándo usarlo

Sí

  • Un solo <h1> por página, con el tema principal.
  • <h2> para cada sección grande; <h3> para dividir dentro de una <h2>.
  • Sin saltarse niveles: después de <h1> viene <h2>, no <h4>.

No

  • Para agrandar un texto que no es título. Eso se hace con CSS.
  • Para poner un texto en negrita. Para eso está <b>.

Figura

Ojo

El número del heading dice la importancia, no el tamaño. Que <h1> se vea grande es solo el estilo por defecto; con CSS un <h3> puede verse más grande que un <h1> y seguir siendo un subtítulo de tercer nivel. Los buscadores y los lectores de pantalla leen la jerarquía, no el tamaño.

Concepto: párrafo

¿Qué es <p>? La etiqueta de párrafo (p de paragraph): un bloque de texto corrido.

Cada <p> empieza en su propia línea y deja un espacio con el siguiente. Los saltos de línea que escribas dentro del código no cuentan: el navegador junta todo el texto de un <p> en un solo bloque y lo acomoda al ancho disponible.

Ejemplo

<h2>Sobre mí</h2>
<p>Estudio desarrollo web y me gusta la fotografía.</p>
<p>Este es mi primer sitio, hecho solo con HTML.</p>

Un <h2> abre la sección y dos <p> la llenan. Cada párrafo se ve como un bloque separado aunque en el código estén pegados.

Error común

Elegir el heading por cómo se ve en vez de por lo que es:

<h1>Mi portafolio</h1>
<h4>Proyectos</h4>
<h1>Contacto</h1>

Pasa porque <h4> "se veía del tamaño justo" y el segundo <h1> "para que resalte". La página queda con dos títulos principales y una sección que depende de un nivel que no existe.

Cómo detectarlo: lee solo los headings de arriba abajo, como un índice; si no forman un esquema con un único título y secciones ordenadas, hay un nivel mal puesto.

Bajar al piso 6

Etiqueta imagen

Concepto

¿Qué es <img>? La etiqueta que inserta una imagen en la página (img de image).

No tiene cierre, porque no envuelve contenido: la imagen no está escrita en el HTML, está en otro archivo, y <img> solo dice dónde buscarla. Por eso todo lo importante va en sus atributos.

src
Source (fuente). De dónde se carga la imagen. Es obligatorio.
alt
Alternative (alternativo). Un texto que describe la imagen. Se muestra si la imagen no carga y lo leen en voz alta los lectores de pantalla para personas ciegas. Siempre ponlo.
width y height
Ancho y alto en píxeles. Opcionales; sin ellos la imagen se muestra en su tamaño original.

Figura

Compara

CriterioImagen propiaImagen de internet
Dónde está el archivoEn una carpeta de tu proyectoEn el servidor de otra página
Qué va en srcLa ruta al archivo: img/perfil.jpgLa URL completa: https://...
Qué pasa sin internetSe ve igualNo carga
Qué pasa si la otra página borra el archivoNadaTu imagen desaparece

Para una imagen propia, el archivo tiene que estar dentro de la carpeta del proyecto. Si está en Descargas o en el Escritorio, el navegador no la va a encontrar cuando subas la página.

Ejemplo

Imagen propia, guardada en la carpeta img del proyecto:

<img src="img/perfil.jpg" alt="Foto de perfil con fondo azul">

Imagen de internet, usando su dirección completa:

<img src="https://www.google.com.pe/images/branding/googlelogo/1x/googlelogo_color_272x92dp.png" alt="Logo de Google">

Error común

La imagen no carga y en su lugar aparece el ícono roto con el texto del alt:

<img src="Mi Foto.JPG" alt="Mi foto">

Pasa casi siempre por el nombre del archivo: tiene espacios, mayúsculas que no coinciden (foto.jpg no es foto.JPG) o la extensión está mal.

Cómo detectarlo: abre la carpeta y compara letra por letra el nombre real con lo que escribiste en src; renombra el archivo en minúsculas y sin espacios (mi-foto.jpg) y corrige el src.

Bajar al piso 7

Rutas

Concepto

¿Qué es una ruta? El camino que le das al navegador para que encuentre un archivo.

Cuando escribes src="img/perfil.jpg", el navegador no busca "perfil.jpg" en toda la computadora: sigue el camino exacto que le diste, carpeta por carpeta. Si una sola carpeta del camino no coincide, no encuentra nada. Hay dos formas de escribir ese camino.

Ruta relativa
Parte desde la carpeta donde está tu archivo HTML. img/perfil.jpg significa "desde aquí, entra a img y toma perfil.jpg".
Ruta absoluta
El camino completo desde el inicio. En internet es una URL entera (https://www.google.com.pe/images/logo.png); en tu computadora empieza desde el disco (C:/Users/ana/proyecto/img/perfil.jpg).

Para tus propios archivos usa siempre relativa. La absoluta de disco (C:/Users/...) solo funciona en tu computadora: cuando subas la página a un servidor, esa carpeta no existe ahí.

Cómo se hace

Para escribir una ruta relativa desde tu HTML hasta un archivo:

  1. Ubica la carpeta donde está tu archivo HTML. Ese es el punto de partida.
  2. Si el archivo está en esa misma carpeta, escribe solo su nombre: perfil.jpg.
  3. Si está en una carpeta de adentro, escribe la carpeta, una barra y el nombre: img/perfil.jpg. Una barra por cada carpeta que entras.
  4. Si está en una carpeta de afuera, escribe ../ para subir un nivel, y luego baja: ../img/logo.png. Un ../ por cada nivel que subes.
  5. Comprueba abriendo la página: si la imagen se ve, la ruta está bien.

Ojo

./ significa "esta misma carpeta" y se puede omitir: ./img/perfil.jpg y img/perfil.jpg son lo mismo. ../ significa "la carpeta de arriba" y no se puede omitir. La barra es /, no \, aunque Windows use la otra.

Pregunta

Tu index.html está en la raíz del proyecto y la imagen banner.jpg está dentro de la carpeta img. ¿Qué escribes en src?

img/banner.jpg. Partes de donde está index.html, entras a img y tomas el archivo. Sin ../, porque no hay que subir ningún nivel.

Bajar al piso 8

Etiquetas de listas

Concepto

¿Qué es una lista en HTML? Un grupo de ítems que el navegador muestra uno debajo del otro, con una marca adelante.

Hay dos etiquetas para el grupo y una sola para cada ítem:

<ul>
Unordered list (lista desordenada). Por defecto cada ítem lleva un punto.
<ol>
Ordered list (lista ordenada). Por defecto cada ítem lleva un número, empezando en 1.
<li>
List item (ítem de lista). Va siempre dentro de <ul> o <ol>, y es la misma etiqueta en las dos.

La palabra que decide cuál usar es orden: si cambiar el orden de los ítems cambia el sentido, es <ol>; si no, es <ul>.

Compara

Criterio<ul> desordenada<ol> ordenada
Qué esÍtems sin secuenciaÍtems con secuencia
Marca por defectoPuntoNúmero
Dónde se usaMenú de navegación, ingredientes, lista de hobbiesPasos de una receta, ranking, instrucciones
PruebaSi los mezclas, se entiende igualSi los mezclas, se rompe

Figura

Ejemplo

<h2>Lo que necesitas</h2>
<ul>
  <li>Harina</li>
  <li>Huevos</li>
  <li>Leche</li>
</ul>

<h2>Cómo se prepara</h2>
<ol>
  <li>Mezclar la harina.</li>
  <li>Agregar los huevos.</li>
  <li>Verter la leche.</li>
</ol>

Los ingredientes van en <ul> porque da igual en qué orden los leas. Los pasos van en <ol> porque no puedes verter la leche antes de mezclar la harina.

Error común

Poner el texto directo dentro de la lista, sin <li>:

<ul>
  Harina
  Huevos
  Leche
</ul>

Pasa porque se piensa que <ul> ya "hace la lista" sola. El navegador muestra las tres palabras pegadas en una sola línea, sin puntos.

Cómo detectarlo: si en pantalla no aparecen las marcas (puntos o números), falta <li>; cada ítem tiene que tener la suya.

Bajar al piso 9

Conclusiones

Conclusión 1

Una página web son tres tecnologías que llegan por una petición. Es un documento HTML que un servidor envía como texto y tu navegador dibuja; CSS le da apariencia y JavaScript, comportamiento. Para que llegue, el DNS traduce el nombre a una IP y HTTP lleva la petición y la respuesta.

Conclusión 2

HTML es marcar contenido dentro de una estructura fija. Cada pedazo de texto se rodea con una etiqueta que dice qué es, los atributos la configuran, y todo vive dentro del mismo esqueleto: <!DOCTYPE>, <html>, <head> para lo que no se ve y <body> para lo que sí.

Conclusión 3

Las primeras etiquetas cubren texto, imágenes y listas. Los headings ordenan por importancia, no por tamaño; <p> agrupa texto corrido; <img> trae una imagen desde una ruta, que casi siempre es relativa al archivo HTML; y <ul> u <ol> agrupan ítems según importe o no su orden.

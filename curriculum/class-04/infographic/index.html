Flexbox — Cómo organizar layouts como un profesional

El sistema de layout que usan Netflix, Spotify y Amazon para organizar sus elementos en fila, centrar contenido y distribuir espacio.

Flex Container e Items

Activa Flexbox en el padre con display: flex y todos sus hijos directos se organizan automáticamente en fila.

Ejes: justify-content y align-items

Flexbox tiene dos ejes. justify-content distribuye en el eje principal (horizontal) y align-items alinea en el eje cruzado (vertical).

Cards con flex-wrap

Combina flex-wrap: wrap con gap para crear grillas de cards que bajan a la siguiente línea si no caben.

.cards {
    display: flex;
    flex-wrap: wrap;          /* Bajan si no caben */
    gap: 20px;
    justify-content: center;
}

.card {
    background: white;
    padding: 20px;
    border-radius: 8px;
    width: 200px;
}

Hover States y Transiciones

La pseudo-clase :hover define estilos al pasar el mouse. transition hace que el cambio sea suave en vez de instantáneo.

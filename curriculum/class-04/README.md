# Layout Moderno con Flexbox

## Resumen

En esta clase final del Módulo 1, dominarás Flexbox—el sistema de layout que revolucionó el diseño web y que usan sitios como Netflix, Spotify y Amazon para organizar sus elementos.

Transformarás tu perfil de una secuencia vertical de elementos a un diseño profesional con header horizontal, cards de contenido organizadas, y navegación estilizada. También aprenderás a crear interactividad visual con estados hover y transiciones CSS.

Al final de la clase, presentarás tu proyecto completo: un perfil personal con wireframe documentado, HTML semántico, CSS estilizado, y layout profesional con Flexbox. Es el cierre de todo lo que has aprendido en el módulo.

**Este lab es CALIFICADO** - Ver rúbrica de evaluación en el lab.

---

## ¿Por qué te sirve?

- **Flexbox es el estándar de la industria para layouts.** Antes de Flexbox, centrar elementos era una pesadilla. Ahora es una línea de código. Este conocimiento te servirá en cualquier proyecto web.

- **Los hover states hacen la diferencia entre "amateur" y "profesional".** Pequeños detalles de interactividad—como cards que se elevan al pasar el mouse—separan los proyectos mediocres de los memorables.

- **Completar un proyecto de principio a fin es una habilidad.** Saber HTML, CSS y Flexbox es útil, pero integrarlos en un proyecto coherente es lo que te hace desarrollador.

---

## ¿Qué haremos en clase?

1. **Analizaremos layouts de sitios populares** - Verás cómo Netflix, Spotify y otros organizan sus elementos y descubrirás que todos usan Flexbox.

2. **Transformarás tu layout con Flexbox** - Convertirás tu header en horizontal, organizarás tu contenido en cards, y centrarás elementos sin dolor.

3. **Agregarás interactividad visual** - Implementarás estados hover y transiciones que harán tu perfil sentirse profesional y pulido.

4. **Presentarás tu proyecto completo** - Mostrarás tu perfil terminado al grupo como cierre del Módulo 1.

## Glosario

| Término | Definición |
|---------|------------|
| **Flexbox** | Sistema de layout unidimensional para organizar elementos |
| **Flex Container** | El elemento padre con `display: flex` |
| **Flex Items** | Los hijos directos del flex container |
| **Main Axis** | El eje principal (horizontal por defecto) |
| **Cross Axis** | El eje perpendicular al principal |
| **justify-content** | Alinea items en el eje principal |
| **align-items** | Alinea items en el eje cruzado |
| **gap** | Espacio entre flex items |
| **:hover** | Pseudo-clase para estado al pasar el mouse |
| **transition** | Animación suave entre estados CSS |

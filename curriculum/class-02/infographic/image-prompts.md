# Image Prompts — Clase 02: Diseña y Estructura

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

---

> **Nota:** Esta infografía no requiere imágenes externas generadas por IA. Todos los conceptos (Mapeo de Wireframes, HTML Semántico, Enlaces de Navegación Interna y Atributo ID) se diseñaron directamente con elementos visuales de CSS y bloques de código con resaltado sintáctico, manteniendo el diseño fluido y la exportación de alta calidad.

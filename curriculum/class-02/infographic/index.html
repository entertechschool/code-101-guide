2. HTML Semántico vs La Sopa de Divs

La etiqueta <div> agrupa, pero no tiene significado para Google ni lectores de pantalla. En su lugar, usamos etiquetas que comunican su propósito nativamente.

<!-- Sopa invisible (Mala práctica) -->
<div class="cabecera">...</div>
<div class="contenido-principal">...</div>

<!-- Estructura Semántica (Se lee, se indexa, se entiende) -->
<header>
    <nav><!-- La Navegación -->...</nav>
</header>

<main><!-- Solo existe un <main> por página -->
    <section>...</section>
</main>

<footer>...</footer>

3. Navegación Interna: El Teletransportador

Permite al usuario moverse entre secciones dentro de la misma página sin recargar, usando Enlaces Ancla.

El Botón (href con #)
<a href="#hobbies">
Coincidencia Exacta
El Destino (id)
<section id="hobbies">
HTML Semántico Uso de etiquetas que describen e informan a Google y navegadores el verdadero propósito del contenido (ej. <nav>, <header>).
Atributo id El DNI de un elemento HTML. Es único, irrepetible por página, nunca lleva espacios y se usa como blanco para enlaces.
Accesibilidad Construir software utilizable por cualquier persona. Un código sin semántica o sin alt en imágenes excluye a millones de usuarios.

# Diseña y Estructura

## Resumen

En esta clase, descubrirás por qué los profesionales diseñan antes de escribir código. Aprenderás a crear wireframes—bocetos visuales que planifican la estructura de una página—usando Excalidraw, una herramienta gratuita y poderosa.

También transformarás tu HTML de la clase anterior usando etiquetas semánticas: elementos que no solo estructuran tu contenido, sino que le dan significado. Entenderás por qué esto importa no solo para ti, sino para personas que usan lectores de pantalla y para motores de búsqueda como Google.

Al final de la clase, tendrás un wireframe completo de tu perfil personal (con secciones para películas, series, libros, o lo que te apasione) y tu HTML reorganizado con navegación interna funcionando.

---

## ¿Por qué te sirve?

- **Los profesionales nunca empiezan a codear sin un plan.** Diseñar primero te ahorra tiempo, reduce errores y te ayuda a comunicar ideas con tu equipo antes de invertir horas de trabajo.

- **HTML semántico no es solo "buena práctica"—es accesibilidad real.** Millones de personas usan lectores de pantalla para navegar la web. Tu código puede incluirlos o excluirlos.

- **Google lee tu página como un lector de pantalla.** Si tu HTML no tiene sentido estructural, tu sitio será invisible para los buscadores. SEO empieza con buen HTML.

---

## ¿Qué haremos en clase?

1. **Entenderemos por qué diseñar antes de codear** - Verás cómo los profesionales planifican sus proyectos antes de escribir una línea de código.

2. **Crearás tu wireframe en Excalidraw** - Diseñarás la estructura completa de tu perfil: header, secciones de contenido (películas, series, libros...), y footer.

3. **Reorganizarás tu HTML con etiquetas semánticas** - Transformarás tu código usando `<header>`, `<main>`, `<section>`, `<nav>` y `<footer>`.

4. **Implementarás navegación interna** - Crearás enlaces que lleven a diferentes secciones de tu misma página.

---

## Objetivos de Aprendizaje

Al finalizar esta clase, podrás:

1. **Diseñar** un wireframe básico usando Excalidraw antes de escribir código
2. **Distinguir** entre etiquetas genéricas (`<div>`) y semánticas (`<header>`, `<section>`)
3. **Explicar** por qué la accesibilidad importa para todos los usuarios
4. **Estructurar** una página con etiquetas semánticas apropiadas
5. **Crear** navegación interna funcional con enlaces ancla (`#`)

## Glosario

| Término | Definición |
|---------|------------|
| **Wireframe** | Boceto visual de baja fidelidad que muestra la estructura de una página |
| **HTML Semántico** | Uso de etiquetas que describen el significado del contenido |
| **Accesibilidad** | Diseño que permite el uso por personas con diversas capacidades |
| **Lector de pantalla** | Software que lee en voz alta el contenido de la pantalla |
| **Enlace ancla** | Link que navega a una sección específica de la misma página usando `#id` |
| **`<header>`** | Etiqueta para el encabezado principal de la página |
| **`<main>`** | Etiqueta para el contenido principal (solo uno por página) |
| **`<section>`** | Etiqueta para agrupar contenido relacionado temáticamente |
| **`<nav>`** | Etiqueta para la navegación |
| **`<footer>`** | Etiqueta para el pie de página |

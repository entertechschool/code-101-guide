LLMs, Tokens, Prompt Scaffolding y Vibe Coding profesional

LLM (Large Language Model)

Motor de completado de texto que predice el siguiente token más probable basándose en el contexto previo. No piensa, no busca en Google, no entiende: calcula probabilidades.

Prompt: "El cielo es..."
  Token más probable → "azul" (95%)

Prompt: "El cielo del planeta Marte es..."
  Token más probable → "rojo" (92%)

Más contexto = predicción más precisa

Tokens y Ventana de Contexto

Un token es una unidad numérica que representa un fragmento de texto. Todo lo que entra y sale de un LLM se mide en tokens. Cuando la ventana se llena, el modelo "olvida" lo anterior.

"Hello, how are you?"     → 5 tokens
"¿Hola, cómo estás?"     → 8 tokens

1 token ≈ 4 caracteres (inglés)
1 token ≈ 3.5 caracteres (español)

Ventana de Contexto = tu historial
  + tu nuevo prompt.
  Si se llena, la IA olvida el inicio.

Prompt Scaffolding

Técnica de construir instrucciones estructuradas por bloques lógicos (rol, contexto, tarea, restricciones y formato) para que la IA no tenga que adivinar nada.

Estructura de un prompt pro:

[ROL]           Actúa como un experto en...
[CONTEXTO]      Mi proyecto es... mi usuario es...
[TAREA]         Genera el código HTML/CSS de...
[RESTRICCIONES] Usa solo estos colores, mobile-first
[FORMATO]       Devuelve en un Artifact renderizable

Vibe Coding: Profesional vs Irresponsable

Programar describiendo lo que quieres en lenguaje natural mientras la IA escribe el código. Tu rol: supervisar, iterar y validar.

❌ Irresponsable ✅ Profesional
Prompt vago → acepta sin leer Prompt scaffolded → evalúa el output
Copia y pega sin entender Entiende la estructura del código
Si falla: "no funciona, arréglalo" Localiza el error → instrucción precisa
El código es una caja negra El código es su responsabilidad
Prompt Instrucción que le das a la IA. La calidad del resultado depende 100% de la calidad del prompt.
Artifact Código que Claude genera y renderiza en vivo al lado del chat. Tu página se construye en tiempo real.
GitHub Pages Hosting gratuito que convierte tu repositorio en un sitio web con URL pública real.
Iteración Refinar resultados de IA con feedback específico: "los botones necesitan 1rem de espacio", no "no me gusta".

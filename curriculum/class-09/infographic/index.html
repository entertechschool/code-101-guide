Algoritmos, Variables, Tipos de Dato y Operadores en JavaScript

1. Algoritmos y Ejecución Secuencial

Un algoritmo es una secuencia finita, ordenada y precisa de instrucciones. JavaScript ejecuta tu código exactamente así: línea por línea, de arriba hacia abajo, sin saltarse nada.

// La precisión importa. Si omites un paso, el código falla.
Paso 1: Detectar el clic en el botón.
Paso 2: Obtener el valor ingresado por el usuario.
Paso 3: Si está vacío → mostrar advertencia.
Paso 4: Si tiene valor → guardar datos y avanzar.

2. Variables: Las cajas de la memoria

Una variable es un espacio en la memoria para guardar un dato. Tienen nombre (variable) y tipo. En JS usamos dos principales:

let intentos = 0;
0 → 1

Caja Abierta: El contenido PUEDE cambiar o reasignarse en el futuro.

const MAX = 10;
10

Caja Sellada: Una vez inicializado, el contenido NO PUEDE cambiar. (Opción por defecto)

3. Tipos de Dato y el inspector typeof

La regla de oro: las comillas definen el tipo, no el contenido. Dependiendo del tipo, el motor de JS decide si sumar, concatenar o dar error.

typeof 42            // → "number" (Azul en consola)
typeof "42"          // → "string" (Negro en consola)
typeof true          // → "boolean"
typeof undefined     // → "undefined" (Caja sin inicializar)

4. La Trampa del "+" y Conversión de Tipos

El operador + hace doble trabajo: suma matemática y concatenación de texto. Si detecta un string en la operación, abandona la suma y pega textos juntos. prompt() siempre devuelve texto.

// ❌ La Trampa:
"5" + 3              // → "53" (Concatenación)
"5" - 3              // → 2    (Matemáticas reales)

// ✅ La Solución: Convertir con Number() o parseInt()
Number("5") + 3      // → 8

// ✨ Forma Moderna: Template Literals (con backticks)
let msg = `Tienes ${edad} años y faltan ${100 - edad}`;

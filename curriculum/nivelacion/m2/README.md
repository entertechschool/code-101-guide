# Nivelación M2 — MyLinks

> 🎯 **Lab integrador del Módulo 2** para alumnos que se incorporaron tarde al curso o no pudieron asistir a las clases 5-8.

---

## ¿Qué es este lab?

Un **proyecto integrador autodirigido** que cubre todos los temas del Módulo 2 en un solo documento: terminal y Git, diseño responsive con DevTools, Figma desde cero, Prompt Scaffolding con IA y deploy en GitHub Pages.

Al final del lab tendrás tu **MyLinks** — el mismo proyecto integrador del M2 — publicado en internet con una URL pública que puedes compartir.

---

## ¿Para quién es?

- Alumnos que se incorporaron al curso después de la Clase 08.
- Alumnos que faltaron a 2 o más clases del Módulo 2.
- Alumnos que necesitan reforzar el M2 antes de entrar al M3.

> Si estás al día con las 4 clases del M2, **este lab no es para ti** — usa el lab oficial de la Clase 08.

---

## ⚠️ Prerrequisito

Necesitas tener **el Módulo 1 completo** — ya sea por las clases regulares o por el [Lab Nivelación M1](../m1/lab/). Este lab asume que ya manejas:

- VS Code + Live Server.
- HTML semántico, CSS, Box Model y Flexbox.
- Cuenta de GitHub funcional con al menos un repo subido.
- Comandos básicos de Git (`init`, `add`, `commit`, `push`).

---

## ⏱️ Tiempo estimado

**6 a 7 horas en un día.** Cabe entre la mañana y la tarde con descanso de almuerzo.

| Bloque | Tiempo |
|---|---|
| Setup (cuentas Claude, Gemini, Figma) | 30 min |
| Parte 1 — Spec Sheet | 30 min |
| Parte 2 — Figma desde cero | 60 min |
| Parte 3 — Prompt Scaffolded | 45 min |
| Parte 4 — Iteración con uiverse.io | 30 min |
| Parte 5 — Extracción a VS Code | 30 min |
| Parte 6 — Responsive con DevTools | 30 min |
| Parte 7 (Desafío) — GitHub Pages | 30 min |
| Cierre y entrega | 15 min |
| **Total** | **~5 h efectivas + buffer** |

---

## 🎯 Qué vas a construir

Un sitio personal tipo Linktree con:

- Diseño en Figma (móvil + escritorio) con tu paleta y tipografía.
- Código generado con Claude usando un prompt scaffolded profesional.
- Botones personalizados con CSS real de uiverse.io.
- Diseño responsive verificado en DevTools.
- **URL pública en GitHub Pages** que puedes compartir en LinkedIn, WhatsApp o donde quieras.

# Nivelación M1 — Mi Perfil Personal

> 🎯 **Lab integrador del Módulo 1** para alumnos que se incorporaron tarde al curso o no pudieron asistir a las clases 1-4.

---

## ¿Qué es este lab?

Un **proyecto integrador autodirigido** que cubre todos los temas del Módulo 1 en un solo documento. Es la forma de ponerte al día sin tener que revisar las 4 clases por separado: aquí están **todos los conceptos juntos**, paso a paso, con mini-explicaciones para que entiendas el porqué de cada cosa.

Al final del lab tendrás tu **Mi Perfil Personal** — el mismo proyecto integrador del M1 — listo para arrancar el Módulo 2.

---

## ¿Para quién es?

- Alumnos que se incorporaron al curso después de la Clase 04.
- Alumnos que faltaron a 2 o más clases del Módulo 1.
- Alumnos que necesitan reforzar el M1 antes de entrar al M2.

> Si estás al día con las 4 clases del M1, **este lab no es para ti** — usa el lab oficial de la Clase 04.

---

## ⏱️ Tiempo estimado

**6 a 7 horas en un día.** Cabe holgadamente entre la mañana y la tarde con un descanso de almuerzo.

| Bloque | Tiempo |
|---|---|
| Setup | 30 min |
| Wireframe | 20 min |
| HTML semántico | 60 min |
| CSS base + Box Model | 60 min |
| Tipografía + Paleta | 30 min |
| Flexbox | 75 min |
| Hover + transiciones | 30 min |
| Cierre y entrega | 15 min |
| **Total** | **~5 h efectivas + buffer** |

---

## 🎯 Qué vas a construir

Una página personal de una sola sección con:

- Estructura HTML semántica (header, main, sections, footer).
- Diseño con paleta y tipografía coherentes.
- Layout responsive básico con Flexbox (header horizontal + cards de favoritos).
- Estados hover con transiciones suaves.
- Repositorio en GitHub con commits descriptivos.

# Nivelación M3 — Mi Mapa de Sueños

> 🎯 **Proyecto de Recuperación integrador del curso** para alumnos que llegan al M3 sin haber hecho el proyecto final, o que necesitan recuperar la integración completa del curso (M1 + M2 + M3).

---

## ¿Qué es este lab?

Un **proyecto de recuperación autodirigido** que integra los **3 módulos del curso** en un solo entregable, escribiendo el código **a mano** (sin asistentes de IA, sin Figma):

- **M1:** HTML semántico, CSS, Flexbox, tipografía, hover.
- **M2:** Responsive con DevTools, media queries, Git, GitHub Pages.
- **M3:** JavaScript — variables, funciones, eventos y manipulación del DOM.

Al final del lab tendrás tu **Mi Mapa de Sueños** — una lista interactiva de tus metas de vida donde, al hacer click en un sueño, se marca como **logrado** con un check verde y un tachado. Todo publicado en internet con tu propia URL.

> 💡 Este es el equivalente **más accesible** del proyecto final regular (`Adivina el Número` de la Clase 12). El JavaScript es más simple: 1 sola interacción visual en lugar de un juego con validación y contador. El lab te da los bloques de código listos para que los copies, los entiendas y los personalices.

---

## ¿Para quién es?

- Alumnos que se incorporaron al curso después de la Clase 12.
- Alumnos que faltaron a 2 o más clases del Módulo 3.
- Alumnos que no pudieron entregar el proyecto final `Adivina el Número` y necesitan demostrar dominio integrador del curso.

> Si estás al día con las 4 clases del M3 y entregaste `Adivina el Número`, **este lab no es para ti** — usa el lab oficial de la Clase 12.

---

## ⚠️ Prerrequisito

Necesitas haber visto algo del **Módulo 1 y del Módulo 2** — sea por las clases regulares o por los labs de nivelación. Este lab asume que ya tienes:

- VS Code + Live Server instalados.
- Cuenta de GitHub funcional.
- Comandos básicos de Git (`init`, `add`, `commit`, `push`).
- Familiaridad mínima con HTML y CSS (no necesitas dominar, el lab te lleva paso a paso).

> Si te falta el M1 o el M2, te recomendamos primero el [Lab Nivelación M1](../m1/lab/) y el [Lab Nivelación M2](../m2/lab/). Si tienes tiempo limitado, puedes intentar este directamente — el lab es autoexplicativo.

## ⏱️ Tiempo estimado

**5 a 6 horas en un día.** Cabe en una tarde con descanso.

| Bloque | Tiempo |
|---|---|
| Setup (carpeta, archivos, repo) | 15 min |
| Parte 1 — Planifica tu sitio | 15 min |
| Parte 2 — Estructura HTML semántico | 45 min |
| Parte 3 — Estilos con CSS y paleta | 60 min |
| Parte 4 — Responsive con DevTools | 30 min |
| Parte 5 — JavaScript: marcar sueño como logrado | 60 min |
| Parte 6 — Hover, transiciones y pulido | 30 min |
| Parte 7 (Desafío) — Git + GitHub Pages | 45 min |
| Cierre y entrega | 15 min |
| **Total** | **~5 h efectivas + buffer** |

---

## 🎯 Qué vas a construir

Un sitio personal de una sola página con tu lista de sueños/metas:

- HTML semántico (`header`, `main`, lista de cards).
- CSS personalizado: tu paleta, Google Fonts, Flexbox.
- Diseño responsive verificado en DevTools (móvil + desktop).
- **JavaScript real:** cada sueño es interactivo — click → se marca como **logrado** (check verde + tachado).
- **URL pública en GitHub Pages** que puedes compartir.

## Pregunta 1

¿Cuál es la diferencia entre `let` y `const` en JavaScript?

- A) `let` es para números y `const` es para texto
- B) `let` permite reasignar el valor, `const` no permite reasignarlo
- C) `const` es más rápido que `let`
- D) No hay diferencia, son sinónimos

> Respuesta: B

---

## Pregunta 2

¿Qué devuelve `typeof "42"` en JavaScript?

- A) `"number"`
- B) `"integer"`
- C) `"string"`
- D) `"text"`

> Respuesta: C

## Pregunta 3

¿Qué resultado produce el siguiente código?

```js
let x = 10;
if (x > 15) {
  console.log('grande');
} else if (x > 5) {
  console.log('medio');
} else {
  console.log('pequeño');
}
```

- A) `grande`
- B) `medio`
- C) `pequeño`
- D) Error de sintaxis

> Respuesta: B

## Pregunta 4

¿Por qué se recomienda usar `===` en lugar de `==` para comparar valores?

- A) `===` es más rápido de ejecutar
- B) `===` compara valor Y tipo, evitando conversiones inesperadas
- C) `==` no funciona con números
- D) `===` solo funciona en navegadores modernos

> Respuesta: B

## Pregunta 5

¿Qué hace la palabra clave `return` dentro de una función?

- A) Imprime un valor en la consola
- B) Detiene la función y devuelve un valor al código que la llamó
- C) Declara una nueva variable
- D) Reinicia la función desde el inicio

## Pregunta 6

¿Cuál es la forma correcta de declarar una función que recibe dos parámetros?

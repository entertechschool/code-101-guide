Decisiones y Lógica Condicional

Enseña a tu código a pensar, comparar y elegir caminos

1. Operadores de Comparación

Toman dos valores, los comparan, y producen siempre un booleano (true o false).

Operador Significado Ejemplo Resultado
=== Igual estricto (valor y tipo) 5 === 5
5 === "5"		 true
false
!== Diferente estricto 5 !== 3 true
> / >= Mayor / Mayor o igual 10 > 5 true
< / <= Menor / Menor o igual 3 < 1 false

2. Operadores Lógicos

Combinan múltiples condiciones (sí o no) para resolver situaciones complejas.

&& (AND)

Exigente: Todas las condiciones deben ser verdaderas. Si una sola falla, todo es falso.

true && true   // → true
true && false  // → false
|| (OR)

Flexible: Basta con que al menos una sea verdadera para que todo sea verdadero.

true || false  // → true
false || false // → false

3. Flujo Condicional: if / else if / else

El programa deja de ser una línea recta y evalúa caminos. Entrará al primer bloque que su condición sea verdadera, e ignorará los demás.

if (puntaje >= 90) {
  // Camino 1: Solo si es mayor o igual a 90
  alert('Excelente');
} else if (puntaje >= 60) {
  // Camino 2: Si no fue el primero, pero es mayor a 60
  alert('Aprobado');
} else {
  // Camino final: Si NINGUNA condición anterior se cumplió
  alert('Sigue intentando');
}

4. Aleatoriedad (Math) y Validación (isNaN)

Herramientas esenciales para construir juegos o validar entradas del usuario.

// 🎲 Generador de Número Secreto (1 a 100):
const numeroVip = Math.floor(Math.random() * 100) + 1;
// random() da decimal (ej: 0.999), 
// * 100 escala (ej: 99.9), 
// floor() redondea hacia abajo (ej: 99),
// + 1 desplaza el rango a 1-100.

// 🛡️ Validación de Usuario: "Not a Number"
if (isNaN(intento) || intento === '') {
  alert("Por favor, ingresa un número válido.");
}
=== vs == Siempre usa === (igualdad estricta). La igualdad doble == es peligrosa porque intenta convertir tipos por detrás ("5" == 5 es `true`).
! (NOT lógico) Invierte un valor. !true se convierte en false. Muy útil para negar condiciones complejas.
NaN Not a Number. Aparece cuando intentas convertir letras a números. Usa isNaN(valor) para detectar si el usuario ingresó algo inválido.

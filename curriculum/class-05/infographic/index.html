Terminal y Git — Cómo trabajar como un desarrollador profesional

Las herramientas que usan en Google, Amazon y Spotify para navegar archivos, guardar versiones de código y colaborar en equipo.

Terminal: El Control Remoto de tu PC

La terminal es una interfaz de texto para ejecutar comandos. Lo que toma 10 clics en carpetas, se hace en una línea.

Comando Qué hace
pwdMuestra en qué carpeta estás
lsLista archivos y carpetas
cd carpetaEntra a una carpeta
cd ..Sube un nivel
mkdir nombreCrea una carpeta nueva
 
$ cd Documents
$ mkdir bootcamp
$ cd bootcamp
$ pwd
/Users/tunombre/Documents/bootcamp

Git: Control de Versiones

Git guarda cada versión de tu código. Si rompes algo, puedes volver atrás. Es como tener "Ctrl+Z" para todo tu proyecto.

Sin Git
proyecto_v1.html
proyecto_v2.html
proyecto_FINAL.html
proyecto_FINAL_FINAL.html
Con Git
proyecto/
  └── .git/
      ├── commit 1
      ├── commit 2
      └── commit 3
$ git commit -m "feat: agregar sección de contacto"
$ git push

El Flujo de Git: add → commit → push

Tres pasos para guardar y subir tus cambios: preparar con git add, guardar en historial con git commit, y subir a la nube con git push.

Git vs GitHub

Git es el programa en tu computadora. GitHub es el servicio en la nube. Como Word vs Google Drive.

Aspecto Git GitHub
Qué es Software en tu PC Sitio web en la nube
Dónde guarda Historial local Almacena en internet
Internet Funciona sin conexión Necesita conexión
Analogía Word (programa) Google Drive (nube)
Terminal / CLI Interfaz de texto para comandos
Repositorio Carpeta con historial de Git
Clone Copiar un repo remoto a tu PC
Commit Guardar un punto en el historial
Push Subir commits a GitHub

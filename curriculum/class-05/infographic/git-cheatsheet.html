Terminal & Git Cheat Sheet

Todos los comandos que necesitas para navegar, versionar y subir tu código

🖥️ Terminal — Navegación
$ pwd
Muestra la ruta completa de la carpeta actual
$ ls
Lista archivos y carpetas del directorio actual
$ cd carpeta
Entra a una carpeta hija
$ cd ..
Sube un nivel (carpeta padre)
$ mkdir nombre
Crea una carpeta nueva
$ touch archivo.html
Crea un archivo vacío
$ code .
Abre VS Code en la carpeta actual
💡 Tip: Tab Autocomplete
Presiona Tab para autocompletar nombres de carpetas y archivos. Ahorra tiempo y evita errores de tipeo.
🔥 Git — Control de Versiones
$ git init
Inicializa un repositorio Git en la carpeta
$ git status
Muestra qué archivos fueron modificados
$ git add .
Prepara todos los cambios para el commit
$ git commit -m "mensaje"
Guarda los cambios en el historial local
☁️ GitHub — La Nube
$ git clone URL
Descarga un repositorio remoto a tu PC
$ git push
Sube tus commits locales a GitHub
$ git pull
Descarga los últimos cambios del remoto
💡 Tip: Mensajes de Commit
Escribí mensajes claros y específicos:
✅ "feat: agregar sección contacto"
❌ "cambios varios"

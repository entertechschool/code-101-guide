Funciones — Los bloques de construcción

DOM, eventos y refactorización en JavaScript

1. Anatomía de una función

Una función es un bloque de código reutilizable con un nombre. Recibe datos (parámetros), hace una tarea y opcionalmente devuelve un resultado con return.

Entrada intento, secreto
→
Función verificarIntento()
→
Salida "correcto" 
function verificarIntento(intento, secreto) {
  if (intento === secreto) return "correcto";
  if (intento > secreto)   return "muy alto";
  return "muy bajo";
}

2. El DOM: JavaScript habla con HTML

El DOM (Document Object Model) es el HTML representado como objetos JavaScript. Con él, JS puede leer, cambiar y estilizar cualquier elemento de la página.

📄 HTML
<p id="mensaje">
  Hola
</p>
⇄
🧠 JavaScript
document.getElementById(
  'mensaje'
).textContent = '¡Hola!'
// 3 herramientas esenciales del DOM
document.getElementById('id')   // Busca un elemento por su id
elemento.textContent = 'texto';       // Cambia el texto visible
elemento.style.color  = 'red';        // Cambia el estilo CSS

3. Eventos: la página responde al usuario

Un evento es cualquier acción del usuario (click, tecla, scroll). Con addEventListener le decimos al navegador: "cuando pase X, ejecuta esta función".

// Conectar el botón con la función
const boton = document.getElementById('btnAdivinar');

boton.addEventListener('click', verificarIntento);
//                              ↑ ↑                  ↑
//                              | Qué evento         La función a ejecutar
//                              | escuchar          (SIN paréntesis: pasamos la referencia)

4. Refactorizar: mejorar sin cambiar lo que hace

En la vida real, los desarrolladores pasan más tiempo mejorando código existente que escribiendo código nuevo. Refactorizar = reorganizar en funciones reutilizables, sin cambiar el comportamiento.

❌ Antes
// Todo lineal, repetitivo
let intento = prompt(...);
if (intento === secreto)
  alert("¡Correcto!");
else if (intento > secreto)
  alert("Muy alto");
else
  alert("Muy bajo");
✅ Después
// Función reutilizable
function verificar() {
  const i = input.value;
  mensaje.textContent =
    comparar(i, secreto);
}

boton.addEventListener(
  'click', verificar
);
Parámetro vs Argumento Parámetro: variable en la definición. Argumento: valor real que pasas al llamarla. function f(x) → x es parámetro; f(5) → 5 es argumento.
return Devuelve un valor desde la función al código que la llamó y termina la ejecución de la función. Sin return, devuelve undefined.
Refactorización Reorganizar código existente para hacerlo más legible y reutilizable, sin cambiar lo que hace. Habilidad clave del trabajo profesional.

# Image Prompts — Clase 11: Funciones - Los Bloques de Construcción

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

> **Nota:** Esta infografía no requiere imágenes externas generadas por IA. Todos los conceptos (anatomía de funciones, DOM, eventos y refactorización) se diseñaron directamente con elementos visuales de CSS, bloques de código con resaltado sintáctico y diagramas hechos con HTML+CSS (incluido el comparativo antes/después).
